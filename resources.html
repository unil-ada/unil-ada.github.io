Reference shelf

No book is required — the slides and notebooks are self-contained. These are the standard references, all free from their authors.

Course
An Introduction to Statistical Learning, with Applications in Python — James, Witten, Hastie, Tibshirani & TaylorThe main companion: regression, classification, dimensionality reduction, clustering, with Python code. Start here.
Maths
Mathematics for Machine Learning — Deisenroth, Faisal & OngLinear algebra, vector calculus, probability, and the derivations behind PCA and Gaussian mixtures.
Deep learning
Deep Learning — Goodfellow, Bengio & CourvilleThe reference for weeks 7–8: networks, training, regularisation, recurrent architectures.
Gaussian processes
Gaussian Processes for Machine Learning — Rasmussen & WilliamsWeek 10; chapters 1–2 cover what the course does.
Reinforcement
Reinforcement Learning: An Introduction, 2nd ed. — Sutton & BartoWeek 13, and the one topic the books above do not cover.
pandas
Python for Data Analysis, 3rd ed. — McKinneyFree online; the pandas book by pandas' author.
