Pricing options under the Heston model and GPs¶

Note: The PyHeston module must be installed. Please refer to this notebook's section of the Junyan Xu's Python Heston Option Pricing Library file for details.

  • pip install git+https://github.com/junyanxu/Python-Heston-Option-Pricer

  • The purpose of this notebook is to demonstrate the fitting of a Gaussian Process Regression model (GP) to option price data.

  • In this notebook, European option prices are generated from the Heston stochastic volatility model.

  • The notebook begins by building a GP Heston model using the underyling and volatility as a two-dimensional input over a maturity time grid.

  • The strike and other model parameters are assumed fixed.

Trains GPs to a static representation of the option price surface at time snapshots of maturities¶

In [6]:
def trainGPs(x_train, f, timegrid):
    gps = []
    
    for time in timegrid:
        print(time)
        
        y_train = []
        for idx in range(len(x_train)):
            y_train.append(f(x_train[idx, 0], x_train[idx, 1], time))
        y_train = np.array(y_train)    
        
        sk_kernel = RBF(length_scale=1.0, length_scale_bounds=(0.01, 100.0))
        gp = gaussian_process.GaussianProcessRegressor(kernel=sk_kernel, n_restarts_optimizer=20)
        gp.fit(x_train,y_train)
        gps.append(gp)
    return gps

Given the trained GPS and a pricing function f, this function predicts the option prices for some test points x_test over a time-grid of different maturities¶

In [7]:
def predictGPs(x_test, f, gps, timegrid):
    
    # Create empty lists to hold the results for each time value
    preds = []
    stds = []
    y_tests = []
    i = 0
    for time in timegrid:
        y_test_ = []
        
        # use the pricing function to calculate the Heston values
        for idx in range(len(x_test)):
            y_test_.append(f(x_test[idx, 0], x_test[idx, 1], time))
        y_test = np.array(y_test_)
        y_tests.append(y_test)
        
        # get the GP's predictions for x_test
        pred, std = gps[i].predict(x_test, return_std=True)
        
        preds.append(pred)
        stds.append(std)
        i += 1
    return y_tests, preds, stds
