# Advanced Data Analytics — your workspace

This is your Nuvolos workspace for the course. Everything in this folder
is yours and persists between sessions.

## What is here

| Folder | What it is |
|---|---|
| `refresher/` | Twelve short Python notebooks, from calculator to pandas. Start here if you have not written Python for a while. |
| `week-NN/` | The runnable material for week NN: demo notebooks, scripts, small data files. A new folder appears after each Monday's session. |

Slides and PDFs are not here — they are on the course site, where you
read them: **https://unil-ada.github.io** (schedule, weekly materials,
the project, the refresher as readable pages).

## The one rule

**`week-NN/` folders are overwritten when material is redistributed.**
If you edit a notebook in a week folder and we push an update to that
week, your edits are gone. So: keep your own work *outside* the week
folders. Copy a notebook to `my-work/` (or any folder you make) before
you change it, or rename the whole week folder.

## Problem sets

Each problem set arrives in its week's folder on the Monday it is handed
out, as a notebook with the statement and the scaffold in one file, plus
its data. Work through it before the exercise session; the solution is
discussed there. Nothing is submitted.

## Running things

- **JupyterLab** opens notebooks. Open a folder in the left-hand file
  browser first, then the notebook: every notebook expects to be run
  from the folder it lives in.
- A **Terminal** is also available from the app list, for `pip`, `git`
  and scripts.
- If a notebook needs a package that is missing, `pip install <name>`
  in a terminal installs it for your workspace. Tell the teaching
  assistant, so it can be added to the image for everyone.
