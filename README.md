# Advanced Data Analytics — course site (static)

Generated by `build.py` from the 2025 week definitions and the course
material corpus (Simon Scheidegger's ADA 2025 repo), vendored into
`materials/week-NN/` with notebooks rendered to HTML via nbconvert.
Rebuild: `uv run --with pyyaml python3 build.py` (needs jupyter-nbconvert
on PATH). Edit week definitions in the source repo, not the output.
